# Projects

## RideShare Application
**Technologies**: *AWS, Python, Flask, SQLite, Docker, Zookeeper, RabbitMQ*

*   Built a backend application mimicking popular cab-sharing services with **high availability** and **fault tolerance**.
*   Architecture: Leader-follower architecture with load balancing.
*   Rerouted reads to follower nodes for performance optimization.
*   Used **SQLite** for in-memory database requirements.
*   Completely hosted on **AWS**.

## Visualization of Graph Algorithms
**Technologies**: *Python, JavaScript, Flask, Sigma JS*

*   Developed a web application to visualize graph algorithms such as **BFS, DFS, Dijkstra’s**, etc.
*   **Backend**: Flask (Python).
*   **Frontend**: JavaScript with the **Sigma JS** library.
